# Utah Startup Map

[**Open the live Utah Startup Map →**](https://jonathanmwagstaff.github.io/HackathonGOED/)

An interactive explorer for Utah's innovation ecosystem. Rather than a conventional geographic map, it is designed as a filterable mind map that makes company hubs and relationships easier to explore by location, sector, headcount, and stage.

Open a company card for details and links. Click bubbles to explore groupings.

The animation is adapted from the Three.js authors' [WebGL GPGPU Birds / Flocking example](https://threejs.org/examples/webgl_gpgpu_birds.html) (MIT License). See the [full attribution](attribution.html).
