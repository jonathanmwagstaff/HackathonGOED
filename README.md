# Utah Startup Map

[**Open the live Utah Startup Map →**](https://jonathanmwagstaff.github.io/HackathonGOED/)

Explore Utah startups in an interactive map and animated swarm. Browse companies by location, sector, headcount, and funding stage, then open a company card for details and links.

Company records are stored in [data/companies.json](data/companies.json). To update the map, edit that file in the repository; changes are published through GitHub Pages.
